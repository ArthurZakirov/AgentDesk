# ⏱️ Effort and scope checkpoints

| When | Then |
| --- | --- |
| **Before substantial work:** The agent is about to start a time-consuming or review-heavy step. | Read and apply the [effort checkpoint procedure](agents-md-references/effort-scope-checkpoints.md) before committing to the step. |
| **During focused technical problem-solving:** The user is troubleshooting why unexpected behavior occurs or expected behavior fails (including failures between interacting systems), or repeatedly seeks explanations, code walkthroughs, visualizations, simplifications, or reviews without reaching stable understanding. | Read and apply the [effort checkpoint procedure](agents-md-references/effort-scope-checkpoints.md) before further debugging or explanation, accounting for investigation effort, review friction, and remaining work. |
