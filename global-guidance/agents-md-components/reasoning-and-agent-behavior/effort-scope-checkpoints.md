# ⏱️ Effort and scope checkpoints

| When | Then |
| --- | --- |
| **Before substantial work:** The agent is about to start a time-consuming or review-heavy step. | Read and apply the [effort checkpoint procedure](agents-md-references/effort-scope-checkpoints.md) before committing to the step. |
| **During focused technical problem-solving:** The user is actively trying to understand or resolve a technical problem and repeatedly asks for explanations, code walkthroughs, visualizations, simplifications, or reviews without reaching stable understanding. | Before another explanation or implementation attempt, read and apply the [effort checkpoint procedure](agents-md-references/effort-scope-checkpoints.md) using actual effort, review friction, and remaining work. |
