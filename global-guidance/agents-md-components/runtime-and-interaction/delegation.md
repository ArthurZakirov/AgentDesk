# 🧩 Delegation

## 🏷️ Naming user-visible delegated conversations

- When you create a separate user-visible conversation to perform delegated work:
  - Set its title at creation time to `[DELEGIERT] <topic or outcome>`.
  - Keep the text after the prefix concise and specific.
  - If the user explicitly requests a different exact title, use that title instead.
- Otherwise, do not add the delegated prefix to ordinary standalone conversations or native internal subagent threads.
